# 💰 Personal Financial Manager

A simple Personal Financial Manager built with Python.

This project is part of my Python learning journey and focuses on practicing basic programming concepts such as functions, lists, dictionaries, loops, and error handling.

---

## ✨ Features

- Add a new transaction
- View all transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Delete a transaction by its index
- Handle invalid menu input
- Prevent deleting from an empty list

---

## 📚 Concepts Used

- Python Functions
- List
- Dictionary
- `return`
- `if / elif / else`
- `while` loop
- `for` loop
- `enumerate()`
- `append()`
- `pop()`
- `len()`
- `try / except`

---

## 📂 Transaction Structure

Each transaction contains:

- Date
- Type (Income / Expense)
- Category
- Description
- Amount
- Location

Transactions are stored as dictionaries inside a list.

---

## 🚀 How to Run

1. Install Python 3.
2. Clone this repository.

```bash
git clone https://github.com/your-username/personal-financial-manager.git
```

3. Run the program.

```bash
python personal_financial_manager.py
```
